# Takayuki Yokoyama — Research

A lightweight, bilingual research portfolio for Takayuki Yokoyama. It consists of plain HTML, CSS, and JavaScript; no framework, build step, external font, or runtime dependency is required.

## Publishing

This repository is intended for GitHub Pages. In Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**. The `index.html` at the repository root is the entry point.

## Editing

Research and publication entries are in `index.html`. Paired `data-en` and `data-ja` attributes contain translations. The appearance is in `style.css`; `script.js` controls the language switch. Publication details reflect publicly available records as of November 2026.
